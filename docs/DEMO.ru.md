# Показ решения

Актуальный порядок на 25.10.2026: камера → новое событие → клип → статистика.
Для аппаратной демонстрации запускайте `start-linq.cmd` по README и сначала
проверьте настоящий ответ воркера. `start.cmd` ниже относится к локальному режиму.
Не используйте этот исторический план как утверждение о готовности всех паттернов:
текущая доступность — `app/pattern-policy.json`, результаты видео —
`docs/pattern-audit-summary-20261025.json`, соответствие кейсу —
`docs/repository-criteria-audit-20261025.json`.

1. Запустить `start.cmd`, открыть http://127.0.0.1:8765. Показать явное разделение режимов.
2. «Анализ записей» → «Падение в комнате» → сценарий падений. При необходимости включить тестовую зону почти на весь кадр, объяснив её учебное назначение. Пройти четыре шага, запустить, открыть кадр и клип. Событие подтвердить оператором.
3. «Прямой эфир» → адрес RTSP/HTTP либо USB/веб-камера. Получить кадр, проверить зоны/шаблон камеры, запустить. Продемонстрировать рамки, текущий таймер, алерт с паттерном и временем.
4. После тревоги подождать 4 с продолжения; показать, что клип появился в «Видеопроисшествиях», пока эфир продолжается. Открыть клип, перейти к моменту тревоги, скачать MP4. Показать фильтры камеры/типа/даты и таймкод клипа.
5. При наличии второго источника нажать «Ещё камера». Два эфира доступны одновременно. Завершить сеансы кнопкой остановки.
6. «Очередь разбора» → приоритет, возраст тревоги → подтверждение/отклонение → экспорт ZIP. «Статистика» → камеры, типы, дни, часы при известном времени съёмки.
7. «Качество модели» → исторический URFD test P/R/F1=0,90 относится к прежнему конвейеру. Не выдавать confidence, validation1,00 или FPS за test accuracy. Показать состояние текущей аппаратной проверки LinQ.

Сильные собственные функции: клипы с предысторией без остановки эфира; очередь приоритетов; нормальная операторская разметка для следующего обучения; карта присутствия; метрическая калибровка; защита от показа устаревших метрик.


Учебные примеры «Без каски», «В каске» и «Огонь» повторяют выбранные изображения;
они проверяют конвейер и не являются независимыми видео. Пример заводской камеры
доступен при наличии соответствующего исходного видео в локальных данных.
Ограждение, груз и конвейер задаются назначением полигона; распознавание самой
конструкции не подтверждено. Привязь, сближение с техникой, защита лица и переноска
с наклоном отключены пользователем. Общий поиск телефона оставлен.
Подробности текущих ограничений — в матрице требований и отчётах видео.
