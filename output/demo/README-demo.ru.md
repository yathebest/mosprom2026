## Как читать разметку

ID — идентификатор трека модели. Красная рамка означает подтверждённый правилами паттерн; UNKNOWN — неопределённое состояние. Рамка с «~ ID» между нейросетевыми замерами — только прогноз положения для плавного просмотра, он не голосует в правилах и не создаёт события. Нейросети получали исходные пиксели. Исходный ход видео сохранён. В файлах 01/02/04 сохранена исходная частота кадров; лабораторное падение экспортировано при частоте анализа 10 кадр/с с сохранением временной шкалы. Внешние полосы находятся за пределами исходного изображения и не закрывают работников.

Счётчик растёт только после фактического времени alert_s из сохранённого нейросетевого прогона. Сырые неассоциированные PPE-кандидаты не нарисованы как нарушения; они сохранены в JSON. Неподтверждённые рамки не удалялись вручную ради красивого результата. В ролике 01 есть ложная детекция человека на станке (ID3). Её статус — UNKNOWN, событие по этому ID не создано. Ложная рамка сохранена в демонстрации; результат не является идеальным.

## Доказательства и ограничения

В `proofs/` лежат неизменённые JSON исходных нейросетевых прогонов: конфигурация, временные метки, координаты, состояния и события. Для 01/02/04 приложены replay JSON с контрольными суммами исходного отчёта: чистое оформление выполнено на CPU без повторного инференса и без пересчёта событий. Изображения активации сохранены по относительным путям, указанным в отчётах. Абсолютные Windows-пути внутри исходных JSON оставлены как свидетельство локального запуска; исходные URL и переносимая структура архива приведены в `sources.json`.

Конец короткого видео не считается концом нарушения. Для касок, жилетов и курения эпизоды при конце наблюдения помечены interrupted, end_s=null; у падения аналогичное прерывание находится в event_updates. Не следует интерпретировать длительность MP4 как длительность нарушения.

Это отобранные интеграционные демонстрации, **не независимый тест Precision/Recall/F1 и не подтверждение качества >0,95 на заводских камерах**. Нет гарантии распознавания всех людей/нарушений; слабые и неизвестные признаки возможны. Дальний ID2 в ролике с касками имеет мало пикселей. Падение и курение не представляют заводское CCTV. Предположения о реальных нарушениях изображённых людей не заменяют решение специалиста и правил конкретного предприятия.
