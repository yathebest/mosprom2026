ВИДЕО ГОТОВО

Назовите источник

Нужно для статистики по времени суток. Если неизвестно, оставьте пустым.

Какие ситуации проверять?

Включите нужные сценарии. Для опасной зоны потребуется разметка на следующем шаге.

Время подтверждения и чувствительность

Метрики падений относятся к порогу 0,90 и выдержке 0,5 с. При изменении настроек результат может отличаться. Скорость в ростах/с не является скоростью в метрах.

Где действует правило?

Кликайте по границе области по порядку. Нужны минимум 3 точки, затем «Сохранить зону».

Калибровка пола для скорости в м/с

Отметьте 4 угла известного прямоугольника по порядку обхода. Эта разметка не заменяет опасную зону.
